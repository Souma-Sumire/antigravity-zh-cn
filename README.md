# Antigravity 汉化

Antigravity 2.0 简体中文补丁。

### 安装

向 Agent 发送以下提示词：

```text
克隆仓库 https://github.com/Souma-Sumire/antigravity-zh-cn 并执行 node install.js
```

### 更新

向 Agent 发送以下提示词：

```text
进入 antigravity-zh-cn 仓库目录，执行 git pull 拉取最新代码，并执行 node install.js 重新注入汉化
```

### 卸载

向 Agent 发送以下提示词：

```text
卸载 Antigravity 汉化补丁
```
